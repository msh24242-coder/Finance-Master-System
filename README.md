# Finance-Master-System
# نظام الإدارة المالية (Finance Master System)

### أقسام النظام:
1. **إدارة الموردين:** تتبع بيانات التجار ومستحقاتهم.
2. **أتمتة LPO:** إصدار وتتبع طلبات الشراء.
3. **مطابقة الفواتير:** ربط كل Invoice بالـ LPO الخاص بها.
4. **تقارير النجاح:** قياس حجم المبيعات والمصاريف فوراً.

### حالة العمل الحالية:
- [x] إنشاء المستودع وتجهيز المجلدات.
- [ ] إدخال بيانات أول 5 موردين.
- [ ] بناء خوارزمية حساب المبالغ المتبقية.
